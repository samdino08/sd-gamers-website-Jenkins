Put profile pictures here.

1. Save a square photo (at least 300 x 300 px, under about 300 KB), e.g. novastrike.jpg
2. Open js/data.js, find the player, and set:  photo: 'images/players/novastrike.jpg'
3. Commit and push. Jenkins deploys the image with the rest of the site.

Use only photos you own or have permission to use. If a file name is wrong or missing,
the site falls back to the generated avatar automatically.
